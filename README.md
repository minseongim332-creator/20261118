# 폰잘알(PONJALAL) — 스마트폰 배우기 · 가족과 소통하기

## v3 현재 작업 상태

- Streamlit은 시작 → 기종 선택 → 기존 홈으로 이동합니다. 검증된 브랜드 원본은 아직 적용하지 않았습니다. 웹판의 기존 배치와 공개 주소는 변경하지 않았습니다.
- 두 판은 `official-lesson-assets.json`을 공유합니다. 제조사 원본을 확인했어도 앱 안에서 표시할 권한이 확인되지 않으면 원본 링크만 제공합니다. 자료가 없는 단계에서는 모의 이미지로 대체하지 않습니다. 아래의 모의 이미지 설명은 이전 판의 기록입니다.
- 웹판 실습은 25개이며, 실습 완료는 원본 스크린샷 확보 여부와 별도로 기록합니다. `REQUIREMENT_TRACEABILITY.md`에 구현·검증·미완료를 구분했고, `node scripts/report_lesson_assets.mjs`로 기종·단계별 원본 공백을 확인할 수 있습니다.

## BAZE 웹판

Node.js 22.12 이상에서 `npm ci`, `npm run dev`로 미리보고, `npm run build`로 게시 파일을 만듭니다. 게시에는 `dist/`만 사용하며 Streamlit 실행 파일은 아래 방식으로 계속 사용할 수 있습니다.

### 기종별 실습 과정

- 시작 화면의 **앱 시작하기**에서 기종을 선택한 뒤 **배우기 시작**을 누릅니다. 상세 화면은 생활 사례 → 모의 화면과 조작 순서 → 따라 하기 → 다른 예시로 혼자 해보기 → 결과 순서입니다. 결과로 넘어가려면 독립 과제를 통과해야 하며, 틀렸던 항목의 복습 안내를 볼 수 있습니다.
- 과정 진도·완료 상태는 같은 브라우저에 저장되며 기존 CSV에 함께 내보내고 가져올 수 있습니다. 입력 중인 값과 모의 클립보드는 보존하지 않습니다. 가족에게 진도를 자동 전송하지 않습니다. 실습은 실제 문자, 인증, QR 링크 접속, 파일 선택·업로드 또는 신청 제출을 하지 않습니다.
- `web/curriculum-data.js`는 과정과 평가 문제, `web/curriculum.js`와 `web/curriculum.css`는 실습과 화면, `web/main.js`·`web/brand.js`는 시작 화면과 이동, `assets/welcome-family.webp`는 사용자 참고 이미지에서 추출한 그림, `web/backup.js`는 CSV 호환을 담당합니다.
- `scripts/test-curriculum.mjs`로 Chromium에서 기종별 15개 과정의 성공·실패·새로고침, 기존 즐겨찾기, CSV 왕복을 반복 검수할 수 있습니다. 앱을 먼저 실행하고 `node scripts/test-curriculum.mjs`를 사용합니다(Playwright와 Chromium이 필요하며, 외부 설치 경로는 `PLAYWRIGHT_MODULE`로 지정 가능).
- 새 과정의 상세 내용은 한국어와 영어로 제공합니다. 나머지 6개 언어의 전체 콘텐츠·오류·가족 화면 번역은 완료되지 않았습니다. 기종별 화면은 교육용 모의 화면으로 모델·버전마다 다른 실제 화면과 완전히 같지 않습니다. 실제 기기·음성 출력·사용자 대상 접근성 검수와 기존 생활 주제 전체의 신규 커리큘럼 전환은 남아 있습니다.
- 게시본은 건드리지 않았습니다. 새 버전을 공개하려면 BAZE에서 이 버전으로 배포를 요청하고 승인해야 합니다. 새 가족 기능의 검수용 연결은 게시용 설정이 아닙니다.

#### 시작 화면과 기종별 자료 개편

- 화면 안내와 따라 하기의 참고 영역에는 Apple 지원·Samsung 지원이 제공하는 공식 원본을 표시합니다. 단계에 맞는 원본을 확보하지 못하면 누락 안내만 표시합니다. 공식 화면은 제조사 원본 링크로 열리며 폰잘알의 가상 입력 실습과는 별개입니다.

- 기본 주소는 재방문에도 시작 화면을 보여 줍니다. **앱 시작하기** 뒤에 기존 기종 설정과 진도는 그대로 이어집니다. 기존 `#home`, `#learn/…` 단계 링크와 `#course/…` 주소도 유지합니다.
- 새 모듈: 앱 설치, 글자 크기 설정, Wi-Fi 연결, 사진 첨부, 파일 첨부. 기존 15개를 포함해 20개입니다. 화면 파일은 `public/lesson-screens/`의 한국어·영어 모의 SVG이며 `node scripts/generate-lesson-assets.mjs`로 화면과 `web/lesson-screen-manifest.json`을 다시 생성합니다. `web/lesson-screens.js`가 기종과 단계에 맞는 화면 및 좌표를 찾습니다. 실제 OS 빌드별 캡처가 아니라 기종 계열별로 그린 교육용 자료입니다.
- `web/onboarding.js`와 `web/onboarding.css`는 시작·기종 선택, `web/simulator-profiles.js`는 실습 기종별 메뉴와 숫자 키보드, `web/curriculum.js`는 소개·개념·화면·따라 하기·독립 실습·평가·완료 흐름을 맡습니다. 기존 브라우저 저장과 CSV를 유지하며 DB는 변경하지 않았습니다. 입력값은 과제 안에만 남습니다.
- 시작·기종 설정은 8개 언어를 지원합니다. 실습 전체, 모의 화면, 가족 상세까지 모두 8개 언어로 번역한 것은 아닙니다. 외부 제조사 이미지·실제 OS 조작은 사용하지 않습니다.

- 로그인 없이 홈, 기존 핵심 학습, 가상 휴대폰과 문제 해결을 열 수 있습니다. 학습·즐겨찾기·설정은 이 주소의 현재 브라우저에 저장합니다. 음성 안내는 기기에 설치된 음성을 사용합니다.
- ‘기존 학습과 백업’에서 기존 한국어 학습과 퀴즈를 열고 `appjalal-v1` CSV를 가져오거나 내려받을 수 있습니다. 메시지와 사진은 탭을 닫거나 새로고침하기 전에 CSV로 내려받아야 합니다. CSV는 암호화되지 않습니다.
- 홈·학습·가상 연습은 연결 없이 쓸 수 있습니다. 갤럭시/아이폰의 Wi-Fi·글자 크기는 별도 경로와 모의 화면을 제공합니다. 다른 공통 학습에는 실제 제조사 화면이 아닌 공용 가상 안내가 남아 있습니다. iPhone Wi-Fi는 [Apple 사용 설명서](https://support.apple.com/guide/iphone/connect-to-the-internet-iphd1cf4268/ios)를 참고했으며 실제 기기의 모델별 검수는 하지 않았습니다.

### 새 가족 공간 연결 및 점검

1. 기존 가족 채팅을 쓰는 프로젝트는 `supabase/schema.sql`과 기존 데이터를 보존합니다. 테스트 프로젝트에서 먼저 `supabase/ponjalal.sql`을 추가로 적용합니다. 새 가족 공간은 기존 가족 채팅이나 CSV를 자동으로 옮기지 않습니다.
2. Supabase에서 익명 로그인을 활성화합니다. 공개 서비스 전에는 자동 가입 방지를 위한 CAPTCHA 연동과 이용량 제한·정리 기준을 별도로 검증합니다. `public/guide-config.json`에 **공개** 프로젝트 URL과 publishable/anon 키만 넣고 테스트할 때 `ponjalalFamilyEnabled`를 `true`로 바꿉니다. 프로젝트 비밀 키는 브라우저에 넣지 않습니다. 기존 이메일 계정은 별도 이메일 리디렉션과 PKCE 설정이 필요합니다.
3. 별도 브라우저/기기로 초대·승인·채팅·읽음·사진·끊김/재접속을 시험합니다. 승인 전, 다른 가족, 연결 해제된 기기는 대화와 사진을 읽을 수 없어야 합니다. 익명 연결을 잃은 경우 다른 관리자의 재초대와 승인이 필요하며, 유일한 관리자 연결을 잃으면 앱에서 복구할 수 없습니다. 새 기기를 승인한 뒤 관리자 역할을 옮기고 이전 기기를 해제해야 합니다.
4. 번역은 발신자가 허용한 글을 수신자가 직접 누를 때만 브라우저 자체 기능으로 시도합니다. 호환 브라우저와 언어 조합만 가능하며, 별도 번역 서버로 보내지 않습니다. 앱이 닫힌 상태의 알림과 음성 메시지는 새 웹판에서 제공하지 않습니다. 실제 운영 전 보관·백업·복구 정책 및 운영자 안내를 확정해야 합니다.

**검증 범위:** 모바일 브라우저의 8개 언어 핵심 화면, 기기 설정·진도·즐겨찾기 유지, 모의 인증 및 CSV 내려받기/재가져오기를 확인했습니다. 별도 Supabase 검수 프로젝트에서 독립된 데스크톱/모바일 브라우저 세션으로 초대, 승인, 실시간 메시지·사진, 읽음, 도움 요청·학습 링크 공유, 기기 연결 해제를 확인했습니다. 테스트 가족 공간은 삭제했습니다. 실제 휴대폰 모델, 모든 언어 조합의 기기 번역과 상세 문구는 미검증입니다. `previewOnly`가 켜져 있어 새 가족 연결은 미리보기에서만 활성화되며 운영 게시본은 변경하지 않았습니다.

**2차 개편:** 기존 자료를 유지하면서 첨부 참고 이미지의 가족 중심 흐름, 바로가기 배열, 눌러야 할 위치 강조를 반영했습니다. 전화·사진·공유·알림·앱 설치/삭제 등은 모의 화면을 사용합니다. iPhone 안내는 [Apple 사용 설명서](https://support.apple.com/guide/iphone/welcome/ios)를 참고했고 공식 스크린샷을 복제하지 않았습니다. 로그인·가입·공동인증서는 가상 값을 입력해 맞는지 확인하며 입력 내용 자체는 어디에도 저장하거나 보내지 않습니다. 새 가족 공간에서 코드로 이름을 먼저 확인하고 언어·기종을 선택합니다. 관리자는 승인된 가족의 표시 언어·기종과 직접 보낸 도움 및 학습 링크만 봅니다. 학습 링크는 수신자가 선택한 기종의 같은 번호(가능한 범위)의 단계를 열며, 기존 진도를 바꾸지 않습니다. 별도 브라우저에서 이 흐름과 접근 철회를 검증했습니다. 실제 기기·어르신 사용성·전체 상세 번역 검수, 공개 운영 보호 설정과 앱스토어 심사는 남아 있습니다.

## 보존한 Streamlit 버전 빠르게 시작하기

Python 3.11 이상을 권장합니다. 저장소 **전체**를 내려받아 `python -m pip install -r requirements.txt` 후 `streamlit run app.py`를 실행합니다. Streamlit Community Cloud에는 이 저장소를 연결하고 실행 파일을 `app.py`로 선택합니다. `assets/`와 `guide_*.py`도 함께 올려야 합니다. 비밀값, 실제 대화 CSV는 저장소에 넣지 마세요.

기존 [Streamlit 주소](https://20261118-7dmaxzfnotja7njkkadwsq.streamlit.app/)를 유지하려면 Community Cloud에서 해당 앱이 `minseongim332-creator/20261118`의 `main` 브랜치와 `app.py`에 연결돼 있는지 확인하세요. 연결이 맞으면 GitHub 변경을 병합한 후 기존 앱에서 새 버전이 열립니다. BAZE 주소의 브라우저 기록이 자동으로 따라오지는 않으니 필요한 기록은 먼저 CSV로 내려받으세요.

- **설정 없이 사용:** 첫 화면, 8개 언어의 첫 화면·핵심 단계·가상 연습, 음성 안내(기기에 해당 음성이 있는 경우), 문제 해결 센터, 안전 교육, 현재 접속 중 학습 기록. 기존 학습·퀴즈·CSV는 ‘기존 학습과 백업’에서 열 수 있습니다.
- **계정과 가족 채팅:** Supabase SQL Editor에서 이 저장소의 [`supabase/schema.sql`](supabase/schema.sql)을 실행합니다. 기존 학습 테이블을 지우지 않습니다. 이메일 인증/복구 이메일을 활성화한 뒤 Streamlit Secrets 또는 실행 환경에 `SUPABASE_URL`, `SUPABASE_ANON_KEY`를 설정합니다. 앱 코드에는 `service_role`이 필요하지 않습니다. 비밀번호 찾기는 아래 복구 메일 템플릿 안내를 따릅니다.
- **채팅 사용:** 계정에 들어간 뒤 채팅방을 만들고, 한 사람씩 쓸 수 있는 24시간 초대 코드를 믿을 수 있는 가족에게 전달합니다. 가족이 직접 수락해야 연결됩니다. 새 구성원은 방의 기존 기록도 열 수 있습니다. 앱을 열어 둔 동안 약 12초마다 새 내역을 불러옵니다(백그라운드 푸시 알림 없음). 첨부는 한 번에 사진 한 장 또는 음성 한 개로, 음성은 최대 25초입니다.
- **선택형 채팅 번역:** 키 없이 쓰는 내장 사전은 교육용입니다. 채팅 번역은 HTTPS LibreTranslate 호환 주소(`GUIDE_TRANSLATE_URL`)와 서버 설정에 따라 선택 키(`GUIDE_TRANSLATE_KEY`)를 등록해야 합니다. 공개 서비스의 비용·언어 한도와 원문 보관 정책은 공급자마다 다릅니다. 직접 운영하는 LibreTranslate는 서비스 요금을 내지 않고 시험할 수 있으나 서버와 해당 언어 모델은 별도로 필요합니다. 받는 사람이 외부 번역을 켜고 보내는 사람이 해당 메시지 번역을 허용한 경우에만 메시지 본문을 전송합니다. 미지원 언어·번역 실패 시 원문을 유지합니다. 사진·음성은 번역에 보내지 않습니다.
- **공유 범위:** 화면·기기를 원격 조작하거나 캡처하지 않습니다. 도움 요청은 질문과 선택한 학습 단계만 미리 확인하고 보내며, 인증 관련 단계 정보는 첨부하지 않습니다. 교육 실습은 예시 정보만 받아 실제 기기를 조작하지 않습니다. 가족이 내 학습 기록을 자동으로 볼 수 없습니다. 로그인한 이용자의 학습 기록은 본인만 저장·확인합니다. 언어와 글자 크기는 현재 주소를 새로고침하면 유지되지만 기본 주소를 새로 열 때는 다시 선택해야 합니다. 로그인은 현재 접속에 한하며 게스트 진도는 접속을 닫으면 사라질 수 있습니다.
- **배포 전 확인:** 미리보기에서 실제 가족 계정·메일·외부 번역 설정을 연결하지 않았습니다. 운영 프로젝트를 준비한 뒤 별도 테스트 계정 세 개로 초대 수락, 연결 해제, 본인 기록과 다른 방의 접근 격리, 텍스트·첨부·복구 이메일·계정 삭제를 순서대로 확인하세요. 이 앱은 종단간 암호화 메신저가 아닙니다. 서비스 관리자는 보관 기간과 처리 절차를 공개해야 합니다.

```text
app.py          공통 디자인·홈·학습·사진·가족 CSV·진도·50개 언어 UI
```

Python 3.11 또는 3.12를 권장합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub → Streamlit Community Cloud

1. GitHub에 저장소를 만들고 **이 폴더의 내용 전체**를 올립니다. app.py뿐 아니라 모듈과 assets 폴더도 필요합니다.
2. 실제 비밀번호, .streamlit/secrets.toml, DB 연결 키, 이용자 CSV를 올리지 마세요. .gitignore가 포함되어 있습니다.
3. Streamlit에서 GitHub 저장소와 브랜치를 선택하고 실행 파일을 `app.py`로 지정합니다.
4. Python 버전을 지원되는 3.11/3.12로 설정하고 배포합니다.
5. 처음에는 ‘열기’ → 계정 화면으로 이동합니다. Supabase 미연결이면 ‘체험 시작하기’를 누릅니다. 로딩 점은 준비 상태 애니메이션이며 실제 다운로드 진행률이 아닙니다. 자동으로 넘기지 않고 사용자가 열기를 누르는 방식을 유지했습니다.
6. Supabase 연결은 앱의 Secrets 설정에 아래 값을 넣습니다. 로컬은 `.streamlit/secrets.toml` 또는 환경 변수로 설정합니다. 이 단락의 시작 화면 설명은 개편 전 동작입니다.

```toml
SUPABASE_URL = "https://YOUR_PROJECT.supabase.co"
SUPABASE_ANON_KEY = "YOUR_PUBLIC_ANON_KEY"
```

`service_role` 또는 프로젝트 secret key는 사용하지 마세요. 이 앱은 로그인한 사용자의 토큰과 RLS로 접근을 제한합니다.

## Supabase 설정

1. 본인의 Supabase 프로젝트를 생성합니다. 이용 한도·이메일 발송 한도·비용은 계정의 현재 제공 조건을 확인하세요. 유료 플랜을 자동 신청하는 코드는 없습니다.
2. SQL Editor에서 `supabase/schema.sql` 전체를 실행합니다. RLS가 켜져 있어야 합니다. 다른 사람의 user_id로 읽고 쓰기가 거부되는지 별도 사용자 2개로 테스트하세요.
3. Authentication에서 이메일/비밀번호 로그인을 활성화하고 이메일 확인을 유지합니다. 아이디는 **이메일**입니다. 앱 자체가 비밀번호를 CSV나 DB 테이블에 저장하지 않습니다.
4. Auth URL 설정의 Site URL과 허용 리디렉션 URL에 실제 배포 주소를 설정합니다.
5. 이메일 확인 템플릿은 Supabase 기본 확인 링크를 사용할 수 있습니다. 메일 인증 후 앱에서 로그인합니다. 운영용 이메일 전송은 SMTP 발송 설정과 한도를 검토하세요.
6. **비밀번호 복구 메일 템플릿**에는 `{{ .Token }}`을 포함하여 복구 코드를 보여 주세요. 사용자가 앱의 ‘비밀번호 찾기’에서 이메일·코드·새 비밀번호를 입력하면 recovery OTP 검증 후 변경합니다. 코드의 유효기간과 재시도 제한은 Supabase 설정을 따릅니다. 이 화면은 기본 복구 링크만 있는 템플릿으로는 완성되지 않으므로 토큰 템플릿 설정이 필요합니다.
7. 회원가입 → 메일 확인 → 로그인 → 학습 완료 → 로그아웃 → 재로그인 순서로 저장 여부를 확인하세요. 로그인 시 로그인 계정의 학습 데이터로 바꾸며 다른 계정의 가족 메시지는 비웁니다.

### 저장 범위

- 계정 연동: 완료 학습, 단계, 즐겨찾기, 퀴즈 결과, 표시 이름, 최근 학습. 로그인 상태는 **현재 Streamlit 접속 세션** 동안 유지합니다. 서비스 장애·새 접속·브라우저 종료 후에는 재로그인이 필요할 수 있습니다. 비밀번호를 저장하는 장기 로그인 쿠키는 구현하지 않았습니다.
- 기존 가족 사진/대화: **CSV 교환 방식**을 유지합니다. 이전 CSV는 새 가족 채팅에 자동으로 이동하지 않습니다.
- CSV: 사진·메시지·기존 학습 진행을 백업합니다. 추가 퀴즈/즐겨찾기도 확장 메타데이터로 저장합니다. 계정 비밀번호/토큰은 포함하지 않습니다. CSV는 암호화되지 않습니다.
- 기기별 최근 변경 충돌을 병합하는 협업 서버는 아닙니다. 동일 계정의 동시 학습은 나중 저장이 앞선 상태를 덮어쓸 수 있습니다.
- 새 계정 삭제 기능은 `supabase/schema.sql` 적용 후 이용할 수 있습니다. 프로필에서 삭제하면 본인 학습·보낸 메시지·만든 채팅방이 삭제됩니다.

## 교육 기능

기존 앱 설치·회원가입·로그인·화면 사진·와이파이 5개와 추가 20개, 총 25개 과정입니다. 스마트폰 기본, 생활 속 활용, 금융·보안으로 분류되며 모든 과정은 한 단계씩 진행합니다. 기종과 앱 버전에 따라 화면이 다르다는 점을 안내합니다. 금융, 민원, 모바일 신분증은 일반적인 사용/안전 교육이며 현재의 법적 요건·발급 대상·금융 상품을 검증한 안내는 아닙니다. 실제 서비스의 공식 안내를 확인해야 합니다.

가상 문자·샘플 사진 첨부·연락처 저장/삭제·가상 전화·설정 화면·송금 확인을 연습할 수 있습니다. 실제 전화, 문자, 송금, 결제, 예약, 민원, 신분증 발급은 발생하지 않습니다. 실제 연락처나 카드번호를 입력하지 마세요. 모의 기기는 Streamlit 위젯 기반이며 실제 Android/iOS 화면을 복제하거나 기기를 제어하지 않습니다.

카테고리별 객관식 20문제와 재도전 기능을 제공합니다. 퀴즈는 추가 20개 과정 기준이며 기존 5개 과정의 별도 퀴즈는 없습니다. 음성은 브라우저 Web Speech 기능으로 한국어 단계를 읽습니다. 음성 종류·네트워크 사용 여부는 기기/브라우저 정책에 따릅니다. 음성 버튼은 사용자가 직접 눌러야 하며 한국어 음성이 없거나 iframe 정책이 막는 환경에서는 사용할 수 없습니다.

## 언어 지원과 한계

- 기존 50개 언어 선택, 페이지 간 선택 유지, 중국어 간체/번체 구분, 아랍어·히브리어 등의 RTL 및 폰트 대체를 유지했습니다.
- 기존 공통 UI도 내장 사전만 사용합니다. 일부 언어는 기존 메뉴를 선택한 언어로, 나머지를 영어로 보여 줍니다. 유료 번역 API 자동 결제 코드는 없습니다.
- **25개 학습 본문, 퀴즈, 가상 연습, 계정 관리의 상세 문구는 현재 한국어입니다.** 이 페이지에는 한국어 콘텐츠 안내를 표시합니다. 50개 언어로 앱 전체가 전문 번역되었다고 표시하지 않습니다. Streamlit 기본 파일 업로드/카메라 도구의 시스템 문구도 브라우저에서 완전히 번역되지 않을 수 있습니다.
- Pretendard와 Google Fonts 대체 글꼴을 온라인으로 가져옵니다. 외부 폰트가 막히면 기기 기본 글꼴로 보입니다. 로고의 한국어는 브랜드 이미지라 번역하지 않습니다.

## 질문 도우미와 선택형 AI

기본 질문 도우미는 무료 **키워드 검색**입니다. 학습 자료에서 연관된 과정을 보여 주며 생성형 AI처럼 표시하지 않습니다. 의미 검색/진단을 하는 기능은 아닙니다.

외부 AI가 필요한 경우 관리자가 별도 제공자와 계약한 뒤 Secrets에 세 값을 모두 설정할 수 있습니다.

```toml
AI_CHAT_URL = "https://YOUR_PROVIDER/v1/chat/completions"
AI_API_KEY = "YOUR_PRIVATE_KEY"
AI_MODEL = "YOUR_CHOSEN_MODEL"
```

OpenAI 호환 chat completions JSON 규격을 지원하는 HTTPS 주소를 사용합니다. 특정 공급자를 기본 연결하지 않습니다. 사용자가 외부 AI 사용을 직접 선택해야 질문과 관련 학습 자료가 전송됩니다. 사진·가족 메시지·계정 비밀번호는 AI로 보내지 않습니다. AI 제공자 비용이 발생할 수 있으며 운영자가 한도·남용 방지·요금 정책을 정해야 합니다. 실패하면 검색 결과를 제공합니다. 실제 AI 서비스 호출은 본 패키지 제작 중 검증하지 않았습니다.
